# Full-Stack Developer Learning Roadmap

An open learning journal and practical curriculum designed to take approximately six months at the recommended part-time pace.

The goal is not to finish a list of courses. The goal is to become able to take a web application from idea to production: design the UI, model the data, build the API, authenticate users, test the system, deploy it, observe it, debug it, and explain the decisions.

## How to use this repository

1. Read the current phase in [`ROADMAP.md`](ROADMAP.md).
2. Use [`STUDY_PLAN.md`](STUDY_PLAN.md) for the current lesson type and bounded resource scope.
3. For a **Learn** lesson, complete the resource's own examples and exercises; do not invent another project.
4. Close the resource and recall the idea in your own words.
5. Build substantial work during **Milestone** and **Integration** lessons.
6. Write a short lesson in `lessons/` and commit the evidence.

## Pace and progression

The recommended pace is roughly 15–20 focused hours per week for approximately six months, or about 360–480 hours overall. Numbered `Day` labels show curriculum order and progress, not calendar dates, study sessions, or required lesson lengths. A familiar lesson may take less than an hour; a difficult lesson may need multiple sessions.

The curriculum alternates resource-led **Learn** clusters with **Milestone**, **Integration**, and **Review** lessons. This keeps projects meaningful and introduces tools such as branches, testing, HTTP, queues, and monitoring when there is real work that needs them.

Use [`DAILY_TEMPLATE.md`](DAILY_TEMPLATE.md) for every lesson. A lesson counts when there is evidence: code, a lesson, a decision, a test, or a shipped improvement.

## Projects

- **Portfolio Foundation** — HTML, CSS, accessibility, responsive design, deployment
- **DevDash** — vanilla JavaScript, DOM, browser APIs, async work, testing
- **ClientFlow Assist** — the evolving capstone combining typed React, Node, PostgreSQL, authentication, production engineering, evaluated AI, and FDE-style delivery

## Teaching workspace

This repository follows the `teach` skill structure:

- `MISSION.md` — why this sprint exists
- `lessons/` — one self-contained numbered lesson per curriculum day
- `reference/` — reusable cheat sheets and concept references
- `learning-records/` — durable lessons and decisions
- `RESOURCES.md` — trusted resources used by the curriculum
- `assets/` — reusable lesson and illustration assets
