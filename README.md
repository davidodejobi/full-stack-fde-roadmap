# 120 Days to Full-Stack Developer

An open learning journal and practical curriculum for a focused 120-day full-stack development sprint.

The goal is not to finish a list of courses. The goal is to become able to take a web application from idea to production: design the UI, model the data, build the API, authenticate users, test the system, deploy it, observe it, debug it, and explain the decisions.

## How to use this repository

1. Read the current phase in [`ROADMAP.md`](ROADMAP.md).
2. Use [`STUDY_PLAN.md`](STUDY_PLAN.md) for the exact daily reading scope and deliverable.
3. Complete the day's supporting DSA/problem-solving and documentation/debugging blocks in the same study plan.
4. Close the resource and recall the idea in your own words.
5. Build the day's small exercise or project improvement.
6. Write a short lesson in `lessons/` and commit the evidence.

The daily four-hour rhythm is:

| Block | Time |
|---|---:|
| Learn | 45 min |
| Recall | 30 min |
| Build | 90 min |
| Practice drill | 30 min |
| Documentation and debugging | 30 min |
| Ship and reflect | 15 min |

Use the full four-hour rhythm in [`STUDY_PLAN.md`](STUDY_PLAN.md) as the default daily target.

Use [`DAILY_TEMPLATE.md`](DAILY_TEMPLATE.md) for every day. A day counts when there is evidence: code, a lesson, a decision, a test, or a shipped improvement.

## Projects

- **Portfolio v1** — HTML, CSS, accessibility, responsive design, deployment
- **DevDash** — vanilla JavaScript, DOM, browser APIs, async work, testing
- **IssueBoard** — React, TypeScript, routing, forms, testing
- **Backend API** — Node, Express, PostgreSQL, REST, authentication
- **ClientFlow** — the capstone combining the stack with Docker, CI, deployment, and monitoring

## Teaching workspace

This repository follows the `teach` skill structure:

- `MISSION.md` — why this sprint exists
- `lessons/` — one self-contained lesson per day
- `reference/` — reusable cheat sheets and concept references
- `learning-records/` — durable lessons and decisions
- `RESOURCES.md` — trusted resources used by the curriculum
- `assets/` — reusable lesson and illustration assets
