# Resources

Use one primary resource for each phase and the official documentation as the reference. Do not complete every course listed here.

## Primary references

- [MDN Curriculum](https://developer.mozilla.org/en-US/curriculum/) — web standards, HTML, CSS, JavaScript, accessibility, Git, testing, and frontend foundations.
- [The Odin Project — Full Stack JavaScript](https://www.theodinproject.com/paths/full-stack-javascript) — alternative explanations and independent projects.
- [Full Stack Open](https://fullstackopen.com/en/) — React, Node, REST, TypeScript, testing, databases, containers, and modern full-stack practice.
- [JavaScript on MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript) — language and Web API reference.
- [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html) — use after JavaScript fundamentals.
- [React Learn](https://react.dev/learn) — components, state, events, effects, and React thinking.
- [Node.js Learn](https://nodejs.org/en/learn) — runtime, modules, asynchronous work, and HTTP.
- [Express documentation](https://expressjs.com/) — routing and middleware reference.
- [PostgreSQL Tutorial](https://www.postgresql.org/docs/current/tutorial.html) — relational modelling and SQL.
- [Docker Get Started](https://docs.docker.com/get-started/) — images, containers, and Compose.
- [Next.js Learn](https://nextjs.org/learn) — introduce Next.js only after React fundamentals.
- [GitHub Skills](https://skills.github.com/) — short, practical GitHub workflows.

## Practice

- [LeetCode 75](https://leetcode.com/studyplan/leetcode-75/) — a bounded DSA practice list.
- [SQL 50](https://leetcode.com/studyplan/top-sql-50/) — focused SQL interview practice.

## Resource rule

When a lesson cites a resource, record the exact page in that day's file. Prefer official documentation, then a structured course, then a reputable explanation. Use AI to translate or review material, not as the source of truth.
