# Mission

## Why I am doing this

Over the next 120 days, I will deliberately build the skills and evidence needed to work as a full-stack developer. I will document the journey so that my future self, or another beginner can follow the path without guessing what to learn next.

## The outcome

By Day 120 I want to be able to:

- build a responsive, accessible frontend;
- explain JavaScript and TypeScript runtime and type behaviour;
- build and test a React application;
- design a relational PostgreSQL database;
- build a validated Node/Express API;
- implement authentication and authorisation responsibly;
- containerise and deploy a full-stack application;
- monitor, debug, and explain the system;
- show the work through public repositories, lessons, and case studies.

## Constraints

- Four focused hours per day.
- One primary resource per topic, not a pile of competing courses.
- Build before consuming more tutorials.
- AI may explain, review, and test; I must own the code and decisions.
- Every day produces a Git commit with evidence.
