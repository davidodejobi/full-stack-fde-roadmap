# Mission

## Why I am doing this

At a flexible pace of approximately six months, I will deliberately build the skills and evidence needed to work as a full-stack developer. I will document the ordered curriculum so that my future self, or another beginner can follow the path without guessing what to learn next.

## The outcome

By the final curriculum milestone I want to be able to:

- build a responsive, accessible frontend;
- explain JavaScript and TypeScript runtime and type behaviour;
- build and test a React application;
- design a relational PostgreSQL database;
- build a validated Node/Express API;
- implement authentication and authorisation responsibly;
- containerise and deploy a full-stack application;
- monitor, debug, and explain the system;
- add an evaluated AI workflow with constrained tools and safe failures;
- discover an ambiguous problem and communicate a defensible solution;
- show the work through public repositories, lessons, and case studies.

## Constraints

- Roughly 15–20 focused hours per week when practical; individual lessons take the time their evidence requires.
- One primary resource per topic, not a pile of competing courses.
- Build before consuming more tutorials.
- AI may explain, review, and test; I must own the code and decisions.
- Every completed lesson produces a Git commit with evidence.
