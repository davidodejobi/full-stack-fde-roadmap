# Illustration workflow

Use illustrations to explain one concept at a time in lessons. Store final images beside the lesson or in this directory with a descriptive name such as `day-014-array-methods.png`.

## Prompt pattern

```text
Create a 16:9 educational illustration for Day [NNN] of a full-stack developer course.

Concept: [one idea]
Audience: beginner-to-intermediate developers
Visual identity: [our palette, character, line style, and mood]
Composition: [what is on the left/right; leave space for captions]
The image should explain the concept through one clear visual metaphor.
Use minimal embedded text. No dense infographic or title banner.
Leave the lower 20% clear for subtitles.
```

Create a style reference image first, then reuse it as a visual reference for future images. Keep the identity original: define our own character, palette, and recurring objects instead of copying another creator's exact artwork.
